## 🚀 ¿Qué tipo de soluciones desarrollo?

Tengo experiencia construyendo soluciones de software en diferentes áreas:

- **Aplicaciones con IA:** Asistentes conversacionales utilizando LLM, RAG, embeddings y bases de datos vectoriales para consultar información empresarial.
- **Procesamiento inteligente de documentos:** OCR, extracción automatizada de datos, clasificación documental y validación de reglas de negocio.
- **Aplicaciones Full Stack:** Interfaces web integradas con servicios Backend, APIs REST y bases de datos relacionales y NoSQL.
- **Automatización de procesos:** Web scraping, tareas programadas, notificaciones e integración entre servicios.
- **Arquitectura de software:** Monolitos modulares, organización Backend por funcionalidades e implementación de lógica de negocio.
